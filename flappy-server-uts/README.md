# Flappy Bird Retro-Arcade 16395 - UTS Pemrograman Web 2026

Game Flappy Bird retro-arcade berbasis web dengan integrasi backend MariaDB/MySQL.

## Panduan Cepat Menjalankan

1. Impor `schema.sql` ke MariaDB/MySQL melalui phpMyAdmin atau MySQL CLI.
2. Jalankan PHP Built-in Server dari folder ini:
   ```bash
   php -S localhost:8000
   ```
3. Buka peramban di `http://localhost:8000`.

Lihat dokumentasi lengkap pada file `README.md` di root repositori.
